# Le Bazar de MSD — conception

Boutique mobile-first pour Dakar : catalogue inférieur à 50 produits, prix en XOF, achat invité et administration des ventes.

## État

Phase 1 autorisée le 29 octobre 2026. Dossier de conception préparé pour revue ; aucune application initialisée, aucun déploiement, aucune transaction réelle.

L'accord de démarrage ne confirme pas les tarifs, le budget exact, les comptes marchands ou les règles commerciales manquantes. Voir [les décisions en attente](docs/decisions/pending.md).
