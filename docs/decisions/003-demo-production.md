# ADR 003 — Séparation démonstration / production

Statut : proposé. Date : 2026-10-29.

Décision : Vercel pour la première démonstration ; environnements, données, stockage et secrets distincts. Aucun vrai paiement dans la démo. Production uniquement après recette et accord explicite.

Conséquences : coût d'une offre adaptée au commercial, base de test à provisionner, contrôle des promotions Git/Vercel, procédure de migration et restauration. Les coûts exacts et fournisseurs restent ouverts.
